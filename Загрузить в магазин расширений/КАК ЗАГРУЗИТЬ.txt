КАК ОПУБЛИКОВАТЬ AURORA ADBLOCK В МАГАЗИНАХ РАСШИРЕНИЙ
====================================================
Всё нужное лежит в этой папке: ZIP-архив, скриншоты 1280×800, промо-картинка 440×280,
тексты (ОПИСАНИЕ.txt) и политика конфиденциальности (PRIVACY.md).
Один и тот же ZIP подходит для Chrome, Edge и Opera. Яндекс Браузер ставит расширения
из Chrome Web Store и каталога Opera — отдельно публиковать не нужно.

ПРОВЕРИТЬ ПЕРЕД ЗАГРУЗКОЙ (2 минуты)
  - Chrome → chrome://extensions → включи «Режим разработчика» → «Загрузить распакованное» →
    выбери папку Aurora AdBlock\extension. Открой пару сайтов и YouTube, нажми на значок расширения.
  - Потом удали эту распакованную копию, чтобы после публикации не было двух.

ШАГ 1. Политика конфиденциальности (нужна ссылка)
  - Уже сделано: политика выложена в репозиторий расширения на GitHub.
  - Ссылка: https://github.com/KIRILLTAN/aurora-adblock/blob/main/PRIVACY.md

ШАГ 2. CHROME WEB STORE (Chrome, Яндекс Браузер, Brave, Vivaldi)
  - https://chrome.google.com/webstore/devconsole — тот же аккаунт разработчика, что для Aurora VPN
    (если его ещё нет: принять соглашение и один раз оплатить 5 $ — это делаешь сам).
  - «Новый элемент» → выбери aurora-adblock-1.0.0.zip из этой папки.
  - Вкладка «Описание в магазине» (Store listing):
      Подробное описание — из ОПИСАНИЕ.txt; Категория — Инструменты; Язык — русский.
      Значок 128×128 уже в ZIP. Скриншоты — screenshot-1/2/3. Маленькая промо-картинка — promo-440x280.png.
  - Вкладка «Конфиденциальность» (Privacy):
      Единственное назначение, обоснование каждого разрешения, «Удалённый код: нет» — из ОПИСАНИЕ.txt.
      Использование данных — ничего не отмечать, три галочки внизу поставить.
      Ссылка на политику — из шага 1.
  - Вкладка «Распространение»: Видимость «Открытый», регионы — все.
  - «Отправить на проверку». Блокировщики с доступом ко всем сайтам проверяют от пары дней до 2–3 недель.
    Если отклонят — пришли мне письмо от Google, поправлю.

ШАГ 3. MICROSOFT EDGE ADD-ONS (бесплатно)
  - https://partner.microsoft.com/dashboard/microsoftedge → зарегистрироваться как разработчик
    (личный аккаунт Microsoft, бесплатно).
  - «Create new extension» → загрузи тот же ZIP.
  - Properties: категория Productivity, ссылка на политику из шага 1.
  - Store listings: язык Русский (можно добавить English — тексты переведу, если нужно),
    описание из ОПИСАНИЕ.txt, значок 300×300 не обязателен, скриншоты и промо — из этой папки.
  - «Publish». Проверка обычно до 7 рабочих дней.

ШАГ 4. OPERA ADD-ONS (по желанию, бесплатно)
  - https://addons.opera.com/developer → войти аккаунтом Opera → «Upload new extension» → тот же ZIP.
  - Заполнить описание, категорию Privacy & Security, скриншоты, ссылку на политику.
  - Opera проверяет вручную, бывает долго (недели).

ОБНОВЛЕНИЯ
  - Подними "version" в src\manifest.json (например 1.0.1).
  - В папке Aurora AdBlock выполни:  npm run build
    (свежие фильтры скачаются, новый ZIP появится в этой папке и в dist\).
  - Chrome: Пакет → «Загрузить новый пакет» → отправить на проверку.
    Edge: Update → загрузить ZIP → Publish. У всех пользователей расширение обновится само.
  - Сетевые фильтры обновляются только вместе с версией расширения (правило Manifest V3),
    поэтому выпускать обновление стоит раз в 1–2 месяца. Косметические фильтры расширение
    обновляет само каждый день.
