# Aurora AdBlock

Расширение-блокировщик рекламы для Chrome, Edge, Яндекс Браузера, Opera, Brave и Vivaldi (Manifest V3).
Это тот же блокировщик, что встроен в браузер Aurora:

- **Те же фильтры:** EasyList, EasyPrivacy, uBlock Origin (filters, badware, privacy, quick-fixes, unbreak), Peter Lowe, RU AdList.
- **Сетевая блокировка:** браузер сам режет запросы по правилам `declarativeNetRequest` (быстро и без доступа расширения к трафику).
- **Косметика и скриптлеты:** движок Ghostery Adblocker скрывает рекламные блоки и запускает скриптлеты uBlock.
- **Раздражители:** cookie-баннеры и прочие всплывашки (выключено по умолчанию, как в Aurora).
- **Пропуск рекламы на YouTube**, если она всё же прорвалась в плеер.
- **Исключения для сайтов**, **«Скрыть элемент»** (кнопкой в окне или правой кнопкой мыши), **счётчики** на вкладке и за всё время.

## Установка

1. Скачайте `aurora-adblock-<версия>.zip` из [последнего релиза](https://github.com/KIRILLTAN/aurora-adblock/releases/latest) и распакуйте в постоянную папку.
2. Откройте `chrome://extensions` (Edge — `edge://extensions`, Яндекс — `browser://extensions`).
3. Включите «Режим разработчика» и нажмите «Загрузить распакованное расширение» → выберите распакованную папку.

[Политика конфиденциальности](PRIVACY.md) — расширение не собирает никаких данных.

## Сборка

Нужен Node.js 20+.

```bash
npm install
npm run build
```

Готовое: папка `extension/` (распакованное расширение) и `dist/aurora-adblock-<версия>.zip` (для магазинов;
копия кладётся в `Загрузить в магазин расширений/` вместе со скриншотами, текстами и инструкцией).
`npm run build:fast` собирает из уже скачанных списков, `npm run icons` перерисовывает иконки.

Перед каждым выпуском поднимайте `version` в `src/manifest.json` — магазины не примут тот же номер дважды.
Сетевые правила обновляются только с новой версией расширения (так требует Manifest V3), косметические
фильтры расширение обновляет само раз в сутки.

## Проверить у себя

1. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
2. Включите «Режим разработчика».
3. «Загрузить распакованное расширение» → выберите папку `extension`.

## Структура

```
src/
  manifest.json      манифест (в сборке к нему добавляются заглушки redirects/)
  background.js      service worker: правила DNR, исключения, счётчики, движок косметики
  content.js         косметика, скрытые элементы, режим «Скрыть элемент»
  youtube.js         пропуск рекламы в плеере YouTube
  popup/             окно по кнопке расширения
  options/           страница настроек
  ui/                общие стили и иконки Aurora
  _locales/          русский и английский
tools/
  build.mjs          сборка
  make-icons.mjs     иконки
```
